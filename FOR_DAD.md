# Friction — install guide for Dad

Hi! This is a free Android app that pauses addictive apps (TikTok, etc.) for a few
seconds so you get a chance to choose intentionally.

## 1. Get the APK onto the phone

- Transfer `Friction-v1.0.0.apk` via USB, email, Signal, Drive, etc.
- Or open the GitHub release page on the phone and download the APK.

## 2. Install

1. Open the APK file on the phone.
2. If Android asks: **Allow from this source** → Install.
3. Open **Friction**.

## 3. Turn on three switches (in the app, tap each red “Off” row)

| # | What | What to enable |
|---|------|----------------|
| 1 | Accessibility | **Friction app guard** → On |
| 2 | Display over other apps | **Allow** for Friction |
| 3 | Battery | **Unrestricted** / ignore optimizations for Friction |

**Xiaomi phones:** also set Battery → **No restrictions**, and turn on **Autostart** if you see it.

## 4. Guard apps

In Friction, check the apps you want to slow down (TikTok, Instagram, …).

## 5. Try it

Open TikTok. You should see a black **Friction** screen with a countdown, then  
“Do you really want to open…?” — **No** is the big button on top.

If you press No and open the app again *immediately*, it might skip once (Android
quirk). Wait a second and try again — then it works.

## Privacy

Everything stays on the phone. No account, no tracking, no internet required.
